# Changelog

## 1.0.0 — 2026-08-21

- Introduced platform-specific binary distributions for Windows x86-64 and
  Linux x86-64 with CPython 3.9.
- Added self-contained example data, locked runtime dependencies, manifests,
  checksums, and SPDX software bills of materials.
- Updated the regression API examples to use `test_size`, `reload_trial`,
  `optimization_objective`, `models_optimize`, `models_assess`, and
  `early_stopping_rounds`.
- Corrected the metric import path to `exgep.data.reg_metrics`.
- Replaced the prior GPL repository distribution with the EXGEP Research Use
  License for this and future proprietary releases. Earlier copies validly
  received under GPLv3 remain governed by the grant accompanying those copies.

# Security policy

## Supported version

Security fixes are provided for the latest EXGEP release only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
`lihuihui@caas.cn` with the subject `EXGEP security report` and include the
affected version, platform, impact, reproduction steps, and any proposed
embargo needs. Do not include confidential data or credentials.

We will acknowledge a complete report as soon as practical and coordinate
validation, remediation, and disclosure. No response-time or fix-time guarantee
is made.

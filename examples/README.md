# Examples

The runnable distribution includes these examples together with complete sample
data. Download a platform archive from the GitHub Release and run the scripts
from its extracted `EXGEP-v1.0.0` directory.

- `train_exgep.py` trains and evaluates an EXGEP regression ensemble.
- `explain_exgep.py` generates explainability outputs from a completed training
  job.

Use `python examples/<script>.py --help` to inspect arguments. These public
copies illustrate the interface; the runtime archive is the supported execution
environment.
